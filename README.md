Python CLI Music Player

This is a simple command-line based music player built using Python and Pygame.
It allows users to select and play MP3 files from a local music folder.

Features
1. Play MP3 files
2. Pause music
3. Resume music
4. Stop playback
5.Auto-detects MP3 files inside the music folder
6.Handles invalid file and folder errors

Technologies Used
1)Python
2)Pygame (for audio playback)
3)OS module (for file handling)

📁 Project Structure
project/
│
├── music/
│   ├── song1.mp3
│   ├── song2.mp3
│
└── main.py


▶ How to Run

1)Install dependencies:

2)pip install pygame

3)Create a music folder and add MP3 files.

4)Run the script:

5)python main.py
